# Visual semantics

Gap and mismatch: cool teal = lower documented problem, amber = medium, rust = greater defined problem. Unknown/unsearched is neutral grey with an explicit label. Gap arrows run evidence/comparator → target gap; proxy arrows run observed measure → target indicator. Width means independent support after deduplication only when documented; length has no evidentiary meaning. Wind is modeled and disabled without valid edges and coordinates. Friction marks typed evidence/access barriers. Observation level is shown explicitly.
